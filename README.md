# CamCard Growth Audit

**Live → https://eddieatadapty.github.io/camcard-flow-rebuild/**

Five ideas to turn more CamCard users into subscribers, each built into a clickable version of CamCard's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they came for, then show that first | +10–20% CR to purchase |
| 02 | Let them make their card before the paywall | +10–20% CR to purchase |
| 03 | Show your 4.7★ where they decide | +5–10% CR to purchase |
| 04 | Turn the paywall into an offer test | +10–15% ARPU |
| 05 | Catch the people who close it | +10–15% ARPU |

Every price, rating and feature comes from CamCard's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for CamCard. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
